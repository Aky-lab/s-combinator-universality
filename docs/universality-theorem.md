# A fixed 38-phase S-only universality construction

This construction combines an explicit finite-machine front end with Cinematic
Strawberry's pinned generic CTS-to-S simulation. Its observation event is a
regular language of closed S trees, and its output comes from the current tree
at the first event. The source program has 38 fixed ordinary binary CTS phases.

The exact S encoder and controller below are the mathematical definitions in
commit [`85a867988442fc423279341200f81634a1e65582`](https://github.com/cstrawberry/predictive-universe/tree/85a867988442fc423279341200f81634a1e65582/docs/paper/related/pure_s_universality).
The new first-event transfer argument is developed in
[the stage proof](cts-event-transfer.md). Its imported and newly written proof
components are identified there, with their verification status.

## Statement

There are a fixed finite root-reset controller `C`, a fixed regular tree
language `H`, a total syntax encoder `E`, and a total current-tree decoder `D`
with the following properties.

For every well-formed finite `INC/DECJZ/HALT` register machine `M` and finite
natural-register input `a`, `E(M,a)` is a finite closed term generated by

```text
T ::= S | (T T).
```

Let `T_0=E(M,a)` and repeatedly invoke `C`. Each invocation starts with the
same control at the current tree's root. Its transition sees only finite
control, whether the focus is S or application, and whether it was entered
from the root, left, or right. It uses stationary control changes, one-edge
moves, and one occurrence contraction of

```text
S x y z -> x z (y z).
```

Only the resulting S tree persists between invocations. There is a fixed
constant `kappa` such that every invocation on every finite S tree terminates
within `kappa*(|T|+1)` primitive microticks, where size counts application nodes
and S leaves. A nonnormal term produces exactly one native contraction; a
normal term produces none. Every term on the encoded trajectory has a next
contraction.

The resulting trajectory satisfies:

1. `M(a)` halts if and only if `T_n` belongs to `H` for some `n`.
2. If `n` is the least such index and the machine's final first register is
   `v`, then `D(T_n)=v`.
3. The encoder has a singly exponential bit-time bound in the explicit binary
   source-description length. Membership in `H` is recognized by one fixed
   bottom-up tree automaton. The decoder has polynomial time and space in the
   current finite tree size and returns either a natural result or rejection.

The chosen register-machine model computes arbitrary partial computable
functions, as shown by the finite two-stack simulation in
[the source theorem](universal-bp2-front-end.md#7-why-the-chosen-source-suffices-for-arbitrary-effective-computation).
Thus this statement supplies computation universality along the specified
fixed reduction trajectory, with explicit encoding and output conventions.

## The four fixed interfaces

**Source CTS.** Let `P` be the 38-phase ordinary binary CTS obtained by the
19-bit one-hot expansion of the fixed UT19 production table. Its first 19
appendants encode the 19 productions; its last 19 appendants are empty. It has
760 total appendant bits and 40 ones.

**Controller.** Let `A` be the pinned `canonicalDispatcher P`, and use
`RootResetFinitePrioritySelector.selectorContract P A`. Its bare-term selector
is `RootResetFiniteAllInputsTraceAgreement.selector P`. Both are fixed before
receiving `M,a`.

**Encoder.** Apply the explicit register-machine-to-BP2 compiler, the compact
BP2-to-UT19 seed compiler, and the 19-bit one-hot translation, obtaining `w`.
Then use the pinned generator

```text
E(M,a) = generator (compileActions P A.tree) w.
```

**Event and result.** `H` is descendant occurrence of the completed fresh Local
for label `(17,true)`, route `0100011`, with 19 completed-appender history
arguments. Every hole in this finite pattern is independent. If no F17 witness
exists, `D` rejects. Otherwise it uses the sufficient limits derived from the
current tree size; practical default-cap refusals are outside this mathematical
definition. On the first preorder witness, `D` reads its frozen field at `LLLR`, decodes that carrier,
prepends the deleted 1, and applies the fixed phase-17 UT19 result grammar.
For the resulting nonempty counter tuple it returns `(first-3)/2`; malformed
syntax, an empty tuple, an even first value, or a first value below 3 is rejected.

The mathematical definitions use the pinned S syntax and the explicitly given
structural algorithms. The independent Python implementation provides a
reproduction and adversarial testing surface for these definitions.

## Proof

### Source computation and the designated event

The [uniform front-end theorem](universal-bp2-front-end.md) produces a nonempty
BP2 program with dense positive labels and all-zero initial counters. It halts
exactly when `M(a)` does. If the source result is `v`, its first final BP2
counter is `2v+3`.

The [compact UT19 theorem](ut19-simulation-invariants.md) preserves each source
instruction and restart. Its first selected-18 event occurs exactly at BP2
termination and has the fixed structural counter grammar. No earlier queue
exhaustion occurs; a nonhalting BP2 execution yields an infinite, nonempty,
event-free tag computation.

The [one-hot theorem](alternating-tag.md) transfers this event to the CTS
prestate at phase 17 with head 1. Each tag microstep has exactly 19 CTS steps,
and the intermediate words have the stated suffix/alignment structure. Write
`c_i` for the ordinary CTS configurations. If the first event is at `c_r`,
then `c_0,...,c_r` are nonempty. The target appendant has 19 bits, so
`c_(r+1)` is nonempty as well. Without an event all `c_i` remain nonempty.

### Every native S sample through first acceptance

The pinned generic construction has an exact root-reset/persistent equality
at every contraction sample, and a premise-free construction of all finite
scheduler stages. The [labelled nonempty-prefix lemma](cts-event-transfer.md#3-the-labelled-nonempty-prefix-lemma)
lifts their exact mutation lists with origin and snapshot annotations.

Stage `h` performs `h` jobs, each replaying exactly the responses for
`c_0,...,c_(h-1)` from the original seed and phase zero. Its clock, fuel,
selected deletion, FRAME, dispatcher, appender, and continuation contexts are
exactly those covered by the independently reviewed
[Local-origin proof](local-event-provenance.md). That occurrence proof accounts
for newly assembled nodes, copies, and rebuilt ancestors. A completed target
shell is born only at the target response's final native contraction; its
frozen audit records that response's post-deletion carrier.

If the source has no event, every finite S prefix is covered by a sufficiently
large nonempty stage, and none of its response origins has the target label.
Consequently no current tree belongs to `H`.

If `r` is the least source-event index, stages through `r` have no target
response. The first job of stage `r+1` reaches it after exactly the earlier
responses `c_0,...,c_(r-1)`. Its final response contraction is the first sample
in `H`. Every target witness at this sample inherits the creation audit of
that same response. Whole-term equality transfers this conclusion from the
exact persistent chains to the root-reset trajectory.

### Current-tree output

For `c_r.data = 1 :: u`, `SelectedResponseTrace.targetDecode` gives the frozen
carrier's decode as `u`. The pinned theorem
`CheckpointRun.decodeCarrier?_of_decode` transfers this to the seed-free public
carrier grammar. The literal audit address is `LLLR`; the frozen-audit lemma
preserves it in the registered contexts.

The [bounded structural reader](s-event-readout.md) implements that grammar
with strict-descendant parsing and memoized continuation comparison. Restoring
1 recovers precisely the CTS event prestate. The
[UT19 result-reader theorem](ut19-readout.md) then returns the BP2 result tuple.
Its first value is `2v+3`, so the fixed arithmetic map returns `v`.

### Bounds on auxiliary computation

Let the source have `d` registers, `I` increments, `J` decrements, and input
sum `s`. Put `k=d+I+4J`. Its BP2 program has

```text
C = 8k+3 counter labels;
L = 168k^2+124k+19+4s commands.
```

For `P_0` the least power of two at least `L+3`, the compact seed has at most
`1+4(C+1)+10P_0(C+2)` tag symbols. A seed of `q` symbols gives the exact initial
S size `16,529+306q`. The bounded subset-XOR construction establishes a singly
exponential bit-time bound in an explicit binary source description.

The event automaton has a fixed cover of `2^1751` states and linear
occurrence-tree evaluation. The result reader has sufficient charged budget
`4096(N+1)^3(c+1)^2` for `N` current-input DAG nodes and fixed code allowance
`c`, with polynomial bit-time and storage. Applying it to an unshared tree is
the special case `N=|T|`. The final arithmetic map has linear bit cost.
[The bounds proof](auxiliary-interface-bounds.md) gives the full representation
conventions and cap accounting.

The controller's every-input linear microtick bound and exact one-contraction
contract are supplied by the pinned selector contract. All four interfaces
therefore have input-size bounds independent of the simulated computation's
running time. This proves the stated composition. QED.
